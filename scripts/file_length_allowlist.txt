# Patterns listed here are exempt from the 1000-line hard ceiling enforced by
# scripts/check_file_length.py. Use glob syntax relative to the repository root.
# Lines starting with `#` and blank lines are ignored.
#
# To apply a custom line ceiling instead of a full exemption, append
# `=max_lines` to the pattern. Underscores are allowed for readability.
# Examples:
#   Cargo.lock
#   patches/**
#   docs/archive/snapshot-2026-01-01.md=1_200
#
# Rules for new entries (exceptions must be expensive):
# - Bare patterns (no cap) are reserved for generated output that churns with
#   every dependency or release update. Everything else gets a cap barely above
#   its current size; caps only ever ratchet down.
# - First-party source needs a split plan, not a permanent cap. Park it here to
#   keep the gate green, then split the file and remove the entry.
# - Stale entries (matching no tracked file) fail the gate. Remove the entry in
#   the same change that deletes, renames, or shrinks the file below the limit.
