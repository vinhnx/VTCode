Local setup guide Report an issue

One workspace, a deliberate workflow

  1. Build VT Code and generate a plugin bound to your binary and workspace.
  2. Install through the local marketplace, restart ChatGPT desktop if needed, then select @VT Code Companion in a new Local Work chat and verify it can fetch the workspace README.
  3. Request a read-only plan. Inspect coverage, truncation, and verification evidence.
  4. Only after an explicit implementation request, try the experimental implementation mode and review its diff.

VT Code enforces workspace trust and execution permissions. The workflow skill complements those policies. Setup never grants trust or installs the plugin automatically.

Current pilot support

  • Codex: local discovery, workspace fetch, and planning demonstrated. Large reviews may still be partial or exceed output limits.
  • Implementation: experimental; a live trial failed during evaluation. The complete workflow is not yet validated.
  • ChatGPT Desktop / Local Work: experimental; install from the local Plugins Directory, select Companion in a new chat, and confirm tool discovery. A connected badge alone is not proof of tool access; one reported session did not expose Companion tools.

This pilot requires Python 3, a compatible local host, and a configured VT Code installation. It does not provide web/mobile access or public registry installation.

Local execution, your model provider

The MCP process uses local stdio and opens no network listener. Model requests can send prompts and repository context to your configured provider. VT Code Companion is free and open source; provider usage may incur charges.

The generated plugin contains machine-specific paths. Generate it on your own machine and keep it private. This website hosts information; it cannot run the MCP service or access your workspace.
