# VT Code Desktop

The macOS desktop workspace is a GPUI Kit client for the local `vtcode desktop-server` process. It is intentionally
non-publishable and excluded from default Cargo builds. See [desktop development](../../../docs/development/desktop-workspace.md)
for protocol, packaging, and local build instructions.

The first local app bundle targets macOS 15 and is ad hoc signed. It is not a Developer ID or notarized distribution.
