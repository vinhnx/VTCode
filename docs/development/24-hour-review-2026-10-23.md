## Risk boundaries checked

- **Authorization:** recent policy changes revoke pending one-shot approvals on
  restrictive policy changes and manager replacement. Evidence:
  `a54d998ab`, [policy gateway](../../crates/codegen/vtcode-core/src/tools/registry/policy.rs),
  and [execution regressions](../../crates/codegen/vtcode-core/src/tools/registry/execution_attempts/tests.rs).
  This does not prove all possible concurrent policy schedules.
- **Network/resource limits:** the DuckDuckGo migration in `a54d998ab` uses a
  fixed initial endpoint, HTTPS same-host redirects, a redirect limit, a bounded
  request timeout, and a 1,000,000-byte streamed response cap. The extracted
  [transport](../../crates/codegen/vtcode-core/src/tools/web_search/transport.rs)
  preserves these controls. Parser and mock tests do not establish live search
  availability or resistance to upstream anti-bot challenges.
- **Context/persistence:** `6ffeec3a6` changes optional usage/archive inputs to
  borrows, with sparse metadata and token-accounting boundary regressions.
  `8070f7769` adds compaction token estimates and explicit failure presentation.
  [Context management](../../src/agent/runloop/unified/context_manager.rs),
  [archive conversion](../../crates/codegen/vtcode-core/src/utils/session_archive/message.rs),
  and [compaction](../../src/agent/runloop/unified/turn/compaction/mod.rs) retain
  distinct provider usage, local estimates, and canonical replay state.
- **Cleanup:** extracted session initialization borrows its caller's session/UI
  owners; guards remain in the iteration scope. Turn finalization retains bounded
  exec cleanup before outcome closure and notification. Session teardown retains
  bounded persistence/exec maintenance and explicitly observed background memory
  finalization. See the [ownership guide](session-orchestration-ownership.md) and
  [session teardown](../../src/agent/runloop/unified/turn/session_loop_runner/orchestration/session_teardown.rs).
  A timeout is not evidence that a backend finished or that all state persisted.
- **Cross-platform packaging:** `df2ffba03` moves branch/event selection into the
  local jq filter while retaining artifact-version matching. The new hermetic
  [release regression](../../scripts/tests/test_release_assets.sh) evaluates the
  actual filter on mixed rows and asserts that excluded runs cause no artifact
  API calls. It does not run hosted CI or execute a Windows/Linux binary.

## Implemented DRY/KISS improvements

- Extracted deferred session initialization and resume restoration without
  relocating guard ownership or introducing a second session loop.
- Extracted request-boundary compaction and ordered turn finalization.
- Extracted headless runtime-prompt preparation and shared completion assessment,
  leaving verification admission, budgets, and task cleanup with execution.
- Split web search into orchestration, parsing, transport, and private tests;
  registry entrypoints now share the parameter schema.
- Split the runtime-handler and OpenAI provider test monoliths into private
  behavioral clusters, retaining shared fixtures and existing leaf test names.
- Unified cache expiration and predicate invalidation through one in-place
  removal helper. New regressions establish zero matching-key clones, correct
  survivor/byte counts, and release of cache-owned values through weak references.
  No end-to-end latency improvement is claimed.

The [organization guide](../guides/code-organization-patterns.md),
[testing guide](testing.md), and affected module maps document the boundaries.
